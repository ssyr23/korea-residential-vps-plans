## 家宽 IP 和机房 IP，差的到底是什么

住宅 IP 出自真实的家庭宽带运营商，比如美国的 Comcast、韩国的 KT、澳洲的 Telstra。平台看到的是一个普通家庭在上网，跟隔壁邻居那条线路没有区别。本地化运营的逻辑也在这里：做韩国站就用韩国住宅 IP，平台更容易把你当成当地卖家，而不是一台挂在机房里的服务器。

机房 IP 走的是数据中心号段，平台一眼能认出这是服务器。有些商家会把机房 IP 包装成“原生 IP”，但原生只说明 IP 的注册地在韩国，不代表它具备住宅属性。以讨论度很高的 VMISS 首尔线路为例，它的测评文里自己写明 IP 是广播 IP、不是严格意义的韩国原生 IP，并且直接建议“必须要韩国原生 IP 做风控严格业务”的人去看双 ISP 家宽方案。这句话基本就是“韩国家庭宽带VPS”这个搜索词的由来——需要的人知道机房 IP 不够用，只是不确定该买哪家。

有一点容易误解：住宅 IP 不等于低延迟。同类韩国机房 VPS 的公开测评里，首尔到国内三网平均延迟大约在 70–80ms 区间，电信能压到 50ms 上下。这是机房线路走优化路由的结果。家宽线路出口在运营商的家用宽带侧，回程未必做同样程度的优化，实际表现可能更差。所以别为了“韩国离得近”来买这类机器，你花钱买的只有 IP。
